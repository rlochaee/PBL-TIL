# 📘 Today I Learned

### 1. 오늘 배운 내용
-Java Collections Framework 활용: List를 사용해 멤버를 동적으로 관리하고, Map과 Set을 활용해 파트별 데이터를 분류하는 로직을 구현함.

- 다형성 기반의 리팩토링: 인터페이스 중심의 설계를 통해 서로 다른 클래스(Lion, Staff)를 효율적으로 관리하는 방법을 익힘.

- 제네릭(Generic): List<Role>과 같이 제네릭을 사용하여 컴파일 시점에 타입을 체크하고 불필요한 테이터가 들어오는 것을 막고 데이터를 사용할 때 복잡한 형변환을 하지 않아도 되게 하는 구조를 적용함.

- 제네릭: 제네릭(Generic)은 자바에서 데이터의 타입(Type)을 일반화하는 것"을 의미. 클래스나 메서드에서 사용할 내부 데이터 타입을 컴파일 시점에 미리 지정하지 않고, 객체를 생성할 때 사용자가 결정할 수 있도록 함.


### 2. 핵심 정리 (내 언어로)
- 배열 vs List: 배열은 처음에 크기를 정해야 하지만, List는 add()를 통해 멤버가 늘어날 때마다 자동으로 크기가 조절됨. 덕분에 몇 명을 등록할지 미리 몰라도 유연하게 프로그램을 짤 수 있음.

- 메서드 활용:

add(): 새로운 멤버 객체를 목록에 추가.

size(): 현재 등록된 멤버가 총 몇 명인지 파악하여 반복문이나 출력에 활용.

isEmpty(): 리스트가 비어있을 때 "등록된 멤버가 없습니다"라는 예외 처리를 수행.

get(i): 인덱스를 통해 특정 순서의 멤버 정보를 가져옴.

for-each/순회: for-each 문을 쓰면 인덱스 관리 없이도 리스트 안의 모든 멤버를 하나씩 꺼내어 정보를 출력하거나 검색하기 매우 편리.

Map과 데이터 분류: 파트별 조회를 구현할 때, 파트 이름을 키(Key)로 사용하는 Map이나 중복을 제거하는 keySet() 개념을 통해 데이터를 그룹화.

제네릭: List<Role>을 통해 데이터를 꺼낼 때마다 일일이 타입을 확인하지 않아도 안전하게 메서드를 호출할 수 있음.

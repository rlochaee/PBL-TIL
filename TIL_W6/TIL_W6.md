# 📘 Today I Learned

### 1. 오늘 배운 내용
- 수동 빈(Bean) 등록: 
@Configuration 클래스(AppConfig)를 만들어 @Bean 어노테이션으로 객체를 직접 스프링 컨테이너에 등록함.

- 자동 빈(Bean) 등록:
 @Component Scan 원리를 활용해 @Service, @Repository, @Autowired 만으로 객체를 자동 생성하고 주입함.

- REST API: 
@RestController와 @GetMapping을 사용해 브라우저에 "Hello, Likelion!" 메시지를 출력하는 API 구현.


### 2. 핵심 정리 (내 언어로)
- 스프링 부트의 핵심인 어노테이션을 활용해 객체 관리 방식을 완전히 전환하는 과정을 학습했다. 어노테이션(Annotation)이란 자바 코드에 추가하는 '메타데이터'로, 컴파일러나 프레임워크에 특정 정보를 전달하는 일종의 주석이다. 이를 활용하면 객체 간의 관계를 코드에서 직관적으로 정의할 수 있어 개발 생산성이 획기적으로 높아지게된다.

-  @Configuration
해당 클래스가 스프링의 설정 정보임을 나타내며, 내부에서 @Bean을 사용해 객체를 수동으로 등록할 때 사용. 
- @Repository, @Service
@Repository는 데이터베이스와 통신 @Service는 핵심 비즈니스 로직이 담긴 계층임을 스프링에게 알려주어 자동으로 빈(Bean)으로 등록되게 함. 이렇게 등록된 객체들은 @Autowired를 통해 필요한 곳에 자동으로 주입되어 연결.
- @RestController
 이 클래스가 웹 요청을 받아 JSON이나 문자열 데이터를 반환하는 창구임을 선언
- @GetMapping은 브라우저의 특정 URL 주소와 자바 메서드를 매핑하여 실제 API가 동작하게 만듦.

### 4. 느낀 점
- 어노테이션을 하나씩 추가하면서 복잡했던 객체 조립 과정을 간소화시키는 과정이 인상적이었다. 마지막 단계에서 브라우저 주소창에 URL을 입력해 "Hello, Likelion!"이라는 문구를 직접 확인하면서 어노테이션이 실제 웹을 움직이는 강력한 도구가 된다는 것을 확인할 수 있었다.
